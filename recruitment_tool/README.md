# 受試者招募工具（Google Apps Script）

綁定在「羽球揮拍動作分析研究－受試者招募與測驗時段調查 (回覆)」試算表上，即時讀取表單回覆。
提供**手機可用的網頁版**，也可以在試算表內開啟同一個面板，兩者都需要帳號密碼登入。

- 每位受試者一顆按鈕，點開可看**所有欄位**
- **time table 分頁**：依 `CONFIG.SESSIONS` 自動切出每 20 分鐘一場的時段（目前共 34 個）
- 在受試者頁面用**下拉選單選時段**，已排給別人的時段不會出現；符合受試者可配合時間的時段排在最前面
- 可以直接**寄出邀請信**、**建立 Gmail 草稿**，或**只排時段不寄信**；time table 會同步填入姓名與 Email
- **時段表編輯模式**：按「編輯時段表」確認後，可用下拉選單手動移動受試者；選到已在其他時段的人會自動移過來
- **已確認勾選框**：受試者回覆 OK 後，在時段表編輯模式勾選「確認」（試算表「已確認」欄）；受試者被移到新時段時會自動取消勾選，需重新確認
- 移動已寄過信的受試者後，該受試者會標示「需注意」，提醒寄更改通知（再寄一次信會自動加上【時間更新】）
- **讀取受試者回覆**：列表自動顯示每位受試者的回信數（💬），詳細頁按「查看回覆信」可依序看到第 1、2…封回覆內容（已去除引用的原信）。只會讀主旨含「羽球揮拍動作分析研究」且由該受試者寄來的信，`xxx@nccu.edu.tw` 與 `xxx@g.nccu.edu.tw` 視為同一人
- 時段總覽：各日期的「可配合 / 最希望 / 已排」人數
- 自動提醒：Email 內學號與填寫學號不符、重複填寫、最希望日期不在可配合日期中、沒有符合的時段

受試者個資只存在 Google 試算表中，本 repo 不含任何回覆資料。

## 安全設計

- 帳密**不寫在程式碼裡**，而是由試算表選單設定，以加鹽 SHA-256 存在 Apps Script 的 Script Properties
- 所有讀資料、建草稿的後端函式都會檢查登入 token（有效 6 小時）
- 連續登入失敗 10 次會暫停登入 15 分鐘
- 收件人固定為試算表中該受試者填寫的 Email，前端無法指定其他收件人
- 寄信前會跳出確認；時段已被他人佔用時會在寄信前拒絕（有鎖定機制，兩人同時操作也不會重複排）

## 安裝（一次性）

1. 開啟回覆試算表 → **擴充功能 → Apps Script**
2. 把預設的 `程式碼.gs` 內容換成本資料夾的 `Code.gs`
3. 左側「檔案」旁的 **＋ → HTML**，檔名輸入 `Index`，貼上 `Index.html` 的內容
   （若之前建立過 `Dialog` 檔案，可以刪除）
4. 儲存，回到試算表並重新整理，上方選單會出現 **受試者工具**
5. **受試者工具 → 設定登入帳密**，輸入帳號與密碼
   （第一次執行會要求授權：讀寫試算表、建立 Gmail 草稿，用表單擁有者帳號同意即可）

## 部署網頁版（手機使用）

1. Apps Script 編輯器右上角 **部署 → 新增部署作業**
2. 類型選 **網頁應用程式**
   - 執行身分：**我**（草稿會建立在部署者的 Gmail）
   - 誰可以存取：**所有人**（手機不需登入 Google，靠本工具的帳密保護）
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`），用手機開啟並加到主畫面

之後修改程式碼時，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 才會更新網頁版。
要更改帳密，重新執行「受試者工具 → 設定登入帳密」即可。

## 修改邀請信內容

編輯 `Code.gs` 最上方的 `CONFIG`：

| 設定 | 說明 |
| --- | --- |
| `SESSIONS` | 測驗場次（日期、開始、結束） |
| `SLOT_MINUTES` / `BUFFER_MINUTES` | 每場分鐘數、場與場之間的緩衝（目前 0） |
| `LOCATION` | 測驗地點 |
| `DURATION` | 預計所需時間 |
| `SENDER` | 寄件者顯示名稱 |
| `SIGNATURE` | 信件結尾署名（每行一項） |
| `NOTES` | 注意事項（每行一點） |
| `REPLY_SUBJECT_KEYWORD` / `REPLY_SEARCH_DAYS` | 讀取回覆時的主旨關鍵字、搜尋最近幾天 |
| `SUBJECT` | 信件主旨（會自動加上受試者姓名） |

信件本文的段落在 `Index.html` 的 `buildLetter()`。每封信在面板中也可以直接修改後再寄出。

**修改場次**：改 `SESSIONS` / `SLOT_MINUTES` / `BUFFER_MINUTES` 後，刪除試算表的「time table」分頁，下次開啟面板會依新設定重建（已排的受試者需重新安排）。
也可以直接在「time table」分頁手動新增或刪除時段列，格式維持「日期 | 時間」即可。
